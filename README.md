# Bakal Goodhue-Cocom — Engineering Portfolio

Plain HTML/CSS/JS. Double-click `index.html` to view it.

- `index.html` — home page (intro, projects, experience, skills, contact)
- `projects/*.html` — one page per project
- `assets/img/` — your photos go here (see `assets/img/PHOTO-NAMES.md`)
- `assets/Bakal_Goodhue-Cocom_Resume.pdf` — the résumé the site links to
- `assets/video/banner.mp4` — optional background video for the top banner (see `assets/video/VIDEO.md`)
